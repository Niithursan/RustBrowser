Website permission request

Requests expire after one minute or when their tab navigates, switches or closes.

Background tabs

Pinned tabs, Keep awake tabs, playing audio, downloads and permission activity are protected. Other sites may need live background activity: use Keep awake or turn sleeping off. Sleeping keeps the page intact.

Browsing preferences

Disabling restoration removes saved session URLs and session recovery files. It does not close active tabs. Private windows never retain either history or sessions.

Clear browsing data

Clearing closes every tab in this window and leaves a blank page. Finish or cancel downloads first. Cookies and site storage are shared by this window's tabs; clearing can sign you out. Bookmarks and downloaded files remain. Library recovery backups are retained to protect recovered bookmarks and may contain old history or permissions. This is not secure disk erasure. New browsing can create new data.

Remembered website permissions

Rules apply to one exact origin and capability. Unsupported permissions and background/cross-origin-frame requests are denied. Revocation closes tabs to end active captures; reopen a page to request again.

Default browser

Rust Browser cannot make itself your default browser. Windows asks you to choose: the button opens Windows Settings at Default apps, where you can select Rust Browser for HTTP and HTTPS links.

Local application diagnostics

Only fixed application event categories, times and counts are kept locally. No browsing addresses, page titles, cookies, passwords or form contents are recorded. Nothing is uploaded. Private windows do not open this store. Clearing browsing history does not clear these records.
