Background tabs

Sleeping keeps inactive pages intact while freeing background activity.

Which tabs stay awake

Pinned tabs, Keep awake tabs, playing audio, downloads and permission activity are protected. Other sites may need live background activity: use Keep awake or turn sleeping off.

Privacy & security

History and sessions

Turning this off forgets your saved tabs; tabs you have open stay open. Private windows never keep history or tabs.

Passwords and forms

Both are off until you turn them on. Private windows never save either.

How saved credentials are stored

Saved passwords and form data are kept by WebView2 in this profile, protected by Windows for your account. Rust Browser cannot list, show, export or import them; remove them with Clear browsing data.

Remembered website permissions

Each rule covers one site and one permission.

How permission rules and revoking work

Permissions Rust Browser does not support are always denied, and so are requests from background pages or from another site embedded in a page. Revoking a permission closes that site’s tabs, so a camera or microphone stops at once; open the page again to be asked again.

Extensions

The shield shows how many requests your extensions blocked on each page; counting slows page loading a little.

An extension can read and change every site you open, in normal and private windows, including passwords you type, so add only extensions you trust.

How extensions are added

Choose the extension’s folder (the one containing manifest.json) after downloading it yourself; apart from its built-in ad blocker, Rust Browser never downloads or adds extensions. Private windows run them too, added again each time one opens; this toolbar runs none, and extension buttons and settings pages are not available here.

Clear browsing data

Choose what to remove from this profile; bookmarks and downloaded files are kept.

What clearing keeps and what it cannot do

Clearing closes every tab in this window first, so open pages cannot keep the cleared data; this profile’s other windows stay open. Finish or cancel downloads before you start. To delete only the history list and keep your tabs, use Clear all history in History.

Cookies and site storage are shared by this window’s tabs; clearing can sign you out. Browsing history covers both Rust Browser’s history list and WebView2’s own. Remembered site permissions include WebView2’s permission settings. Library recovery backups are retained to protect recovered bookmarks and may contain old history or permissions. This is not secure disk erasure. New browsing can create new data.
