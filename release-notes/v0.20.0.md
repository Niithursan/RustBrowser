Rust Browser v0.20.0 is the first published release. It is an early, experimental
Windows browser written in Rust that shows websites with Microsoft WebView2. It is
not a release candidate and not yet a replacement for Firefox, Chrome or Edge.

## What it does

- Tabs and up to 8 normal windows on one profile, with pinned and sleeping tabs,
  Ctrl+Shift+T to reopen closed tabs, and session restore after a restart or crash.
- Private windows with their own temporary storage.
- Bookmarks with folders, browsing history, downloads, find in page, zoom and print
  preview.
- Can be chosen as the Windows default browser; links from other apps open in the
  window you used last.
- Opt-in password saving and form autofill through WebView2 (both off until you
  turn them on), and bookmark import from an exported bookmarks HTML file.
- **New in 0.20:** a new layout with tabs as cards and a single menu, and support
  for browser extensions you add yourself from a folder, such as uBlock Origin Lite
  for ad blocking. Rust Browser never downloads extensions for you.

## Install

1. Install the prerequisites if you do not have them (see Requirements).
2. Download `rust-browser-v0.20.0-windows-x64-setup.exe` and its `.sha256` file from
   this release.
3. Check the download in PowerShell, in the folder where you saved both files:

   ```powershell
   (Get-FileHash .\rust-browser-v0.20.0-windows-x64-setup.exe -Algorithm SHA256).Hash.ToLowerInvariant()
   Get-Content .\rust-browser-v0.20.0-windows-x64-setup.exe.sha256
   ```

   The SHA-256 value printed first must equal the start of the second line.
4. Run the setup file. It installs for your Windows user only and needs no
   administrator rights.
5. A portable ZIP is also attached (`rust-browser-v0.20.0-windows-x64.zip`); extract
   it and run `rust-browser.exe`.

Settings, bookmarks and history are kept in `%LOCALAPPDATA%\RustBrowser\v0.1` and
survive upgrades and uninstall. See INSTALL_WINDOWS.md in the repository for
upgrades, uninstalling and the portable copy.

## Builds are unsigned

These builds are **not signed** with a code-signing certificate. Windows
SmartScreen will warn that the publisher is unknown ("Windows protected your PC").
To run it, choose **More info**, then **Run anyway**, but only after the SHA-256
check above matches. Download Rust Browser only from this repository's Releases
page; files attached to CI runs are test builds, not releases.

## Requirements

- Windows 10 (version 1809 or later) or Windows 11, x64. Only Windows 11 has been
  tested; Windows 10 is untested.
- The **Microsoft Edge WebView2 Runtime** (Evergreen). It is already on most
  Windows 11 PCs; otherwise get it from Microsoft's WebView2 download page.
- The **Microsoft Visual C++ v14 Redistributable (x64)**, latest supported version,
  from Microsoft. Setup checks that both are present; it does not download or install
  them.

## Known limitations

- Builds are unsigned (see above), and there is no automatic updater: check this
  page for new versions.
- Websites are rendered by WebView2, not by a Rust engine.
- Extensions: there are no extension buttons or settings pages; extensions run with
  their default settings. They run only in normal windows, never in private windows.
  Each extension can read and change every website you open.
- Saved passwords cannot be imported from another browser, listed or viewed; they
  can only be removed all at once with Clear browsing data.
- Bookmark folders cannot contain folders; imported nested folders become top-level
  folders.
- No sync, no profile manager, no reader mode, no translation.
- Tested on one Windows 11 PC by the developer and the owner; other hardware,
  languages, screen readers and display setups have had limited testing.

## Reporting problems

- Bugs: open an issue in this repository. Do not include passwords, cookies,
  personal browsing addresses or profile files.
- Security problems: report them privately on GitHub: open the repository's
  **Security** tab and choose **Report a vulnerability**. Please do not use public
  issues for security problems.
