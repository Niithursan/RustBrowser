Rust Browser v0.23.0 is an early browser written in Rust. It is the first release
for Linux as well as Windows: on Windows it shows websites with Microsoft WebView2,
and on Linux with the distribution's own WebKitGTK. It is meant for everyday
browsing, but it is young: read the known limitations below before relying on it.

## What it does

- Tabs and up to 8 normal windows per profile, with pinned and sleeping tabs,
  Ctrl+Shift+T to reopen closed tabs, and session restore after a restart or crash.
- Separate profiles for your own roles (for example personal, work and school), each
  with its own sign-ins, cookies, history, bookmarks, passwords, extensions, tabs and
  settings.
- Private windows with their own temporary storage.
- Bookmarks with nested folders and site icons, a bookmarks bar, browsing history,
  downloads, find in page, zoom and print preview.
- Can be chosen as the default browser; links from other apps open in the profile
  you used last.
- A built-in ad blocker, saved passwords and form filling (off until you turn them
  on), and bookmark import from an exported bookmarks HTML file.

## New in 0.23

- **Linux.** Rust Browser now runs on Linux, with the same toolbar, tabs, windows,
  private windows, library, downloads, site permissions, profiles and settings as on
  Windows. This release has a package for Ubuntu and Debian (`.deb`) and one for
  Arch Linux. Each installs the browser, a launcher with New window and New private
  window, and its icon. See "What differs on Linux" below.
- **Ads are blocked from the start.** On Windows the official uBlock Origin 1.77.2
  comes with the browser, unchanged and checked against its published SHA-256, and
  runs with its own panel under the shield. On Linux the browser downloads hBlock's
  list of about 420,000 ad, tracking and malware domains from
  `hblock.molinero.dev`, prepares it (about 15 seconds the first time) and
  downloads it again weekly. It is on by default, including in profiles from
  0.22.2; turning it off in Settings > Extensions, or removing it, keeps it off.
- **Extensions in private windows (Windows).** The built-in uBlock Origin and the
  extensions you added now run in private windows too. To make that possible, a
  private window's pages keep their cookies, cache and site storage in a temporary
  folder while the window is open; the folder is removed when the window closes, or
  at the next start after a crash.
- **Address suggestions.** As you type, the address field completes a site you have
  visited, with the added part selected, and a list under it shows what Enter will
  do and up to six matching pages from your history and bookmarks. Suggestions come
  only from your own library; nothing you type leaves the device before Enter.
- **A new new-tab page.** A large clock with a greeting and the date above the
  search, a row of site tiles (your favorites, then the sites you visit most), recent
  pages as cards, and new backgrounds: four drawn wallpapers in a dark and a light
  version, or **Your picture**, a PNG, JPEG or WebP of up to 6 MB kept in your
  profile folder.

## Fixes

- One click on a tab's close icon closes the tab; a click on the icon itself
  started a tab drag before.
- Home shows the new-tab page on the first click; the first Home showed a blank
  page before.
- What you type in the address field stays while the suggestion list is open; a
  background update such as a page title could replace it.
- Opening a private window while another browser process starts no longer risks
  removing the new window's temporary folder.

## Upgrading from 0.22.2 (Windows)

Install over 0.22.2 with Setup, or replace the portable copy. Profiles, settings,
bookmarks, history, sessions, saved passwords and extensions are kept; the library
database stays at schema 5 and the session format is unchanged, so no migration
runs. The built-in uBlock Origin is added to each profile when that profile
first starts.

## Install on Windows

1. Install the prerequisites if you do not have them (see Requirements).
2. Download `rust-browser-v0.23.0-windows-x64-setup.exe` and its `.sha256` file from
   this release.
3. Check the download in PowerShell, in the folder where you saved both files:

   ```powershell
   (Get-FileHash .\rust-browser-v0.23.0-windows-x64-setup.exe -Algorithm SHA256).Hash.ToLowerInvariant()
   Get-Content .\rust-browser-v0.23.0-windows-x64-setup.exe.sha256
   ```

   The SHA-256 value printed first must equal the start of the second line.
4. Run the setup file. It installs for your Windows user only and needs no
   administrator rights.
5. A portable ZIP is also attached (`rust-browser-v0.23.0-windows-x64.zip`); extract
   it and run `rust-browser.exe`.

Settings, bookmarks and history are kept in `%LOCALAPPDATA%\RustBrowser\v0.1` (other
profiles in its `profiles` folder) and survive upgrades and uninstall. See
INSTALL_WINDOWS.md in the repository for upgrades, uninstalling and the portable copy.

## Install on Ubuntu or Debian

1. Download `rust-browser-v0.23.0-linux-amd64.deb` and its `.sha256` file.
2. In the folder where you saved both, check the download. It must print `OK`:

   ```bash
   sha256sum -c rust-browser-v0.23.0-linux-amd64.deb.sha256
   ```

3. Install it; apt also installs WebKitGTK and the other libraries it needs:

   ```bash
   sudo apt install ./rust-browser-v0.23.0-linux-amd64.deb
   ```

Remove it with `sudo apt remove rust-browser`. The package was built and checked on
Ubuntu 24.04 (x86-64); other Debian-based releases with WebKitGTK 2.40 or newer
should work but are untested.

## Install on Arch Linux

1. Download `rust-browser-v0.23.0-arch-x86_64.pkg.tar.zst` and its `.sha256` file.
2. Check the download. It must print `OK`:

   ```bash
   sha256sum -c rust-browser-v0.23.0-arch-x86_64.pkg.tar.zst.sha256
   ```

3. Update your system first (Arch packages are built against the current
   libraries), then install it:

   ```bash
   sudo pacman -Syu
   sudo pacman -U rust-browser-v0.23.0-arch-x86_64.pkg.tar.zst
   ```

The package is named `rust-browser-git`, as when you build it with `makepkg` from
`packaging/linux/arch`, so either replaces the other. Remove it with
`sudo pacman -R rust-browser-git`. If a later Arch update breaks it, build it again
from the PKGBUILD in the repository.

On both Linux systems the browser keeps its data in
`~/.local/share/rust-browser/v0.1`.

## Builds are unsigned

These builds are **not signed**. On Windows, SmartScreen will warn that the
publisher is unknown ("Windows protected your PC"). To run it, choose **More info**,
then **Run anyway**, but only after the SHA-256 check above matches. The Linux
packages have no signature and come from no package repository, so they are not
updated by `apt` or `pacman`; the SHA-256 check is the only check of the download.
Download Rust Browser only from this repository's Releases page; files attached to
CI runs are test builds, not releases.

## Requirements

- **Windows:** Windows 10 (version 1809 or later) or Windows 11, x64. Only Windows
  11 has been tested; Windows 10 is untested. The **Microsoft Edge WebView2 Runtime**
  (Evergreen), already on most Windows 11 PCs, and the **Microsoft Visual C++ v14
  Redistributable (x64)**, latest supported version, from Microsoft. Setup checks
  that both are present; it does not download or install them. The portable ZIP
  does not check: without the Redistributable, Windows shows a missing-DLL error.
- **Linux:** x86-64, WebKitGTK 2.40 or newer and an X11 session, or Wayland with
  XWayland. Saved passwords need a running desktop keyring (GNOME Keyring, KWallet
  or another Secret Service); without one nothing is saved.

## What differs on Linux

- WebKitGTK cannot run browser extensions. Add from folder uses only an
  extension's declarative blocking rules (such as uBlock Origin Lite's); its
  panel, scripts and settings pages never run, and there is no blocked-request
  count. The shield's panel has a switch that turns blocking off for one site.
- Passwords are kept in your desktop keyring, and are filled only when you choose
  them from the key button in the address field.
- A sleeping tab's page is closed and loads again, where it was, when you select it.
- In a virtual machine without a graphics card, pages can stay blank. Start the
  browser with `WEBKIT_DISABLE_DMABUF_RENDERER=1` (and, if that is not enough,
  `WEBKIT_DISABLE_COMPOSITING_MODE=1`).

## Known limitations

- Builds are unsigned (see above), and there is no automatic updater.
- Websites are rendered by WebView2 or WebKitGTK, not by a Rust engine.
- Each extension can read and change every website you open. On Windows, only the
  panel of an extension that blocks requests opens (from the shield); other
  extension pages, such as uBlock Origin's dashboard, do not open.
- While an extension is added on Windows, pages report blocked requests to the
  shield, which made a 300-request test page load about 11% slower on the test PC.
  Turn off Settings > Extensions > Count blocked requests to avoid it.
- Private windows follow "Show tabs down the side" from normal windows but cannot
  change it there.
- Saved passwords cannot be imported, listed or viewed; they can only be removed all
  at once with Clear browsing data.
- The "Who's browsing?" picker appears at every plain start once there is more than
  one profile; there is no setting to turn it off yet.
- On Linux, camera and microphone requests are untested, and there is no package
  for Arm computers or for distributions other than Debian, Ubuntu and Arch.
- No sync, no reader mode, no translation.
- Tested on one Windows 11 PC and on Ubuntu 24.04 in containers and a virtual
  machine. The Arch package is built, tested and installed in a container, but has
  not been used for browsing on an Arch desktop. Other hardware, languages, screen
  readers and display setups have had limited testing.

## Reporting problems

- Bugs: open an issue in this repository. Do not include passwords, cookies,
  personal browsing addresses or profile files.
- Security problems: report them privately on GitHub: open the repository's
  **Security** tab and choose **Report a vulnerability**. Please do not use public
  issues for security problems.
