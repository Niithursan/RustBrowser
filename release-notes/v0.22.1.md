Rust Browser v0.22.1 is the second published release of an early Windows browser
written in Rust that shows websites with Microsoft WebView2. It is meant for everyday
browsing on Windows 11, but it is young: read the known limitations below before
relying on it.

## What it does

- Tabs and up to 8 normal windows per profile, with pinned and sleeping tabs,
  Ctrl+Shift+T to reopen closed tabs, and session restore after a restart or crash.
- Separate profiles for your own roles (for example personal, work and school), each
  with its own sign-ins, cookies, history, bookmarks, passwords, extensions, tabs and
  settings.
- Private windows with their own temporary storage.
- Bookmarks with nested folders and site icons, a bookmarks bar, browsing history,
  downloads, find in page, zoom and print preview.
- Can be chosen as the Windows default browser; links from other apps open in the
  profile you used last.
- Opt-in password saving and form autofill through WebView2, bookmark import from an
  exported bookmarks HTML file, and browser extensions you add yourself from a
  folder, such as uBlock Origin Lite. Rust Browser never downloads extensions.

## New in 0.22

- **Full screen is the page alone.** A video's full-screen button now fills the whole
  monitor with the page, even from a maximized window; the toolbar and side columns
  come back when you press Esc. For the first four seconds a notice at the top names
  the site ("www.youtube.com is now full screen - Press Esc to exit").
- **The blocker's own panel.** With an ad-blocking extension added, clicking the
  shield opens that extension's own panel under it (for uBlock Origin Lite: the
  filtering mode for the site, Remove an element, Create a custom filter, Report an
  issue). Right-click the shield for the details it showed before.
- **Resize from every edge.** Drag the left, right or bottom edge or a bottom corner
  of a window that is not maximized, as in other Windows apps.
- **Menus on tabs and bookmarks.** Right-click a tab (or press Shift+F10 on it) to
  duplicate, pin, move or close it, close the others, or reopen a closed tab;
  middle-click closes any tab. Right-click a bookmark or folder on the bookmarks bar
  to open it in a new tab, window or private window, open a whole folder in tabs,
  edit, rename, delete or copy it, or add a bookmark or folder beside it.
- **A steadier tab strip.** Tabs share the strip equally, so a page changing its title
  no longer moves the others, and they keep their width after you close one until
  the pointer leaves the strip. Long titles fade out, pinned tabs are icon-only, and
  the list of all tabs is a chevron next to the new-tab button.
- **A quieter address line.** An encrypted page shows a plain lock; loading no longer
  widens the badge and moves the address.
- **The shield appears only when it can help:** once you add an extension that can
  block requests, and never in private windows.
- **The profile button appears** once there is more than one profile.
- **Plainer wording** in Settings and Clear browsing data, and a clearer toolbar while
  Settings covers the page.

## Fixes

- **Security:** the `cookie` library (used by Wry) is updated to 0.18.3 for
  RUSTSEC-2026-0594, where private cookie nonces could repeat in processes that fork.
  This is why the release is 0.22.1: the v0.22.0 build was stopped by this advisory,
  published the same day, and was never released.
- **Security:** the `url` library is updated to 2.5.9 for RUSTSEC-2026-0592, a stack
  overflow a web page could cause with a deeply nested `blob:` address.
- Tabs down the side are one row tall again; since the equal-width tab strip each
  row was as tall as a horizontal tab is wide.
- The address field's right-click menu (Cut, Copy, Paste, Select all) opens below
  the toolbar in full; it was cut off at the toolbar's edge.
- Reopening a dropdown right after closing one no longer closes it again.
- A tab whose page has no icon shows the default globe from the start.
- The release metadata file states the library database schema the build uses (5);
  the v0.21.0 file said 3.

## Upgrading from 0.21.0

Install over 0.21.0 with Setup, or replace the portable copy. Profiles, settings,
bookmarks, history, sessions, saved passwords and extensions are kept; the library
database stays at schema 5 and the session format is unchanged, so no migration
runs.

## Install

1. Install the prerequisites if you do not have them (see Requirements).
2. Download `rust-browser-v0.22.1-windows-x64-setup.exe` and its `.sha256` file from
   this release.
3. Check the download in PowerShell, in the folder where you saved both files:

   ```powershell
   (Get-FileHash .\rust-browser-v0.22.1-windows-x64-setup.exe -Algorithm SHA256).Hash.ToLowerInvariant()
   Get-Content .\rust-browser-v0.22.1-windows-x64-setup.exe.sha256
   ```

   The SHA-256 value printed first must equal the start of the second line.
4. Run the setup file. It installs for your Windows user only and needs no
   administrator rights.
5. A portable ZIP is also attached (`rust-browser-v0.22.1-windows-x64.zip`); extract
   it and run `rust-browser.exe`.

Settings, bookmarks and history are kept in `%LOCALAPPDATA%\RustBrowser\v0.1` (other
profiles in its `profiles` folder) and survive upgrades and uninstall. See
INSTALL_WINDOWS.md in the repository for upgrades, uninstalling and the portable copy.

## Builds are unsigned

These builds are **not signed** with a code-signing certificate. Windows
SmartScreen will warn that the publisher is unknown ("Windows protected your PC").
To run it, choose **More info**, then **Run anyway**, but only after the SHA-256
check above matches. Download Rust Browser only from this repository's Releases
page; files attached to CI runs are test builds, not releases.

## Requirements

- Windows 10 (version 1809 or later) or Windows 11, x64. Only Windows 11 has been
  tested; Windows 10 is untested.
- The **Microsoft Edge WebView2 Runtime** (Evergreen). It is already on most
  Windows 11 PCs; otherwise get it from Microsoft's WebView2 download page.
- The **Microsoft Visual C++ v14 Redistributable (x64)**, latest supported version,
  from Microsoft. Setup checks that both are present; it does not download or install
  them. The portable ZIP does not check: without the Redistributable, Windows shows a
  missing-DLL error.

## Known limitations

- Builds are unsigned (see above), and there is no automatic updater.
- Websites are rendered by WebView2, not by a Rust engine.
- Extensions run only in normal windows, never in private windows, and each one can
  read and change every website you open. Only the panel of an extension that blocks
  requests opens (from the shield); other extension pages, such as uBlock Origin
  Lite's dashboard, do not open, and there are no other extension buttons.
- While an extension is added, pages report blocked requests to the shield, which
  made a 300-request test page load about 11% slower on the test PC. Turn off
  Settings > Extensions > Count blocked requests to avoid it.
- Private windows follow "Show tabs down the side" from normal windows but cannot
  change it there.
- Saved passwords cannot be imported, listed or viewed; they can only be removed all
  at once with Clear browsing data.
- The "Who's browsing?" picker appears at every plain start once there is more than
  one profile; there is no setting to turn it off yet.
- Windows only. Linux support is being developed separately and is not part of this
  release.
- No sync, no reader mode, no translation.
- Tested on one Windows 11 PC; other hardware, languages, screen readers and display
  setups have had limited testing.

## Reporting problems

- Bugs: open an issue in this repository. Do not include passwords, cookies,
  personal browsing addresses or profile files.
- Security problems: report them privately on GitHub: open the repository's
  **Security** tab and choose **Report a vulnerability**. Please do not use public
  issues for security problems.
