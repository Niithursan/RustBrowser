Rust Browser v0.21.0 is an early, experimental Windows browser written in Rust that
shows websites with Microsoft WebView2. It is not a release candidate and not yet a
replacement for Firefox, Chrome or Edge.

## What it does

- Tabs and up to 8 normal windows on one profile, with pinned and sleeping tabs,
  Ctrl+Shift+T to reopen closed tabs, and session restore after a restart or crash.
- Private windows with their own temporary storage.
- Bookmarks with nested folders, browsing history, downloads, find in page, zoom and print
  preview.
- Can be chosen as the Windows default browser; links from other apps open in the
  window you used last.
- Opt-in password saving and form autofill through WebView2, bookmark import from an
  exported bookmarks HTML file, and browser extensions you add yourself from a
  folder, such as uBlock Origin Lite. Rust Browser never downloads extensions.

## New in 0.21

- **Shield at the end of the address line.** It shows which of your extensions can
  block requests and how many requests were blocked on the current page, as
  WebView2 reports them. It has no ad blocker of its own, cannot say which
  extension blocked a request, does not count requests inside frames from other
  sites, and cannot turn blocking off for one site.
- **Library beside the page.** Bookmarks, history and downloads open in a column at
  the right while the page stays usable (Ctrl+Shift+B, or from the menu). Drag its
  edge, or use the arrow keys on it, to resize it.
- **Tabs down the side.** Settings > Appearance > Show tabs down the side moves the
  tab list to a column at the left of every window. It is off by default.
- **New-tab tiles.** Favourites show their site's icon (saved when you visit the
  site) or their first letter, and the new-tab page has an optional background
  drawn from the theme's colours.
- Bookmark imports preserve nested folders; older library databases migrate to the
  nested-folder schema without removing saved bookmarks.
- The native title bar and border follow the selected theme on supported Windows
  versions. Button feedback is animated unless reduced motion is requested.
- The menu (⋮) opens as a sidebar, and the toolbar was polished.

## Install

1. Install the prerequisites if you do not have them (see Requirements).
2. Download `rust-browser-v0.21.0-windows-x64-setup.exe` and its `.sha256` file from
   this release.
3. Check the download in PowerShell, in the folder where you saved both files:

   ```powershell
   (Get-FileHash .\rust-browser-v0.21.0-windows-x64-setup.exe -Algorithm SHA256).Hash.ToLowerInvariant()
   Get-Content .\rust-browser-v0.21.0-windows-x64-setup.exe.sha256
   ```

   The SHA-256 value printed first must equal the start of the second line.
4. Run the setup file. It installs for your Windows user only and needs no
   administrator rights.
5. A portable ZIP is also attached (`rust-browser-v0.21.0-windows-x64.zip`); extract
   it and run `rust-browser.exe`.

Settings, bookmarks and history are kept in `%LOCALAPPDATA%\RustBrowser\v0.1` and
survive upgrades and uninstall. See INSTALL_WINDOWS.md in the repository for
upgrades, uninstalling and the portable copy.

## Builds are unsigned

These builds are **not signed** with a code-signing certificate. Windows
SmartScreen will warn that the publisher is unknown ("Windows protected your PC").
To run it, choose **More info**, then **Run anyway**, but only after the SHA-256
check above matches. Download Rust Browser only from this repository's Releases
page; files attached to CI runs are test builds, not releases.

## Requirements

- Windows 10 (version 1809 or later) or Windows 11, x64. Only Windows 11 has been
  tested; Windows 10 is untested.
- The **Microsoft Edge WebView2 Runtime** (Evergreen). It is already on most
  Windows 11 PCs; otherwise get it from Microsoft's WebView2 download page.
- The **Microsoft Visual C++ v14 Redistributable (x64)**, latest supported version,
  from Microsoft. Setup checks that both are present; it does not download or install
  them.

## Known limitations

- Builds are unsigned (see above), and there is no automatic updater.
- Websites are rendered by WebView2, not by a Rust engine.
- Extensions run with their default settings; there are no extension buttons or
  settings pages. They run only in normal windows, never in private windows. Each
  extension can read and change every website you open.
- While an extension is added, pages report blocked requests to the shield, which
  made a 300-request test page load about 11% slower on the test PC. Turn off
  Privacy & security > Extensions > Count blocked requests to avoid it.
- Private windows follow "Show tabs down the side" from normal windows but cannot
  change it there.
- Saved passwords cannot be imported, listed or viewed; they can only be removed all
  at once with Clear browsing data.
- No sync, no profile manager, no reader mode, no translation.
- Tested on one Windows 11 PC; other hardware, languages, screen readers and display
  setups have had limited testing.

## Reporting problems

- Bugs: open an issue in this repository. Do not include passwords, cookies,
  personal browsing addresses or profile files.
- Security problems: report them privately on GitHub: open the repository's
  **Security** tab and choose **Report a vulnerability**. Please do not use public
  issues for security problems.
