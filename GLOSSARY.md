# Rust Browser

A desktop web browser. This glossary names the parts of the browser's own interface (the chrome) and how people choose its look.

## Appearance

**Theme**:
The colour set the browser's own interface is drawn in, chosen once per profile: Dark, Black, Slate, Plum or Light. A theme never changes how websites look.
_Avoid_: Skin, colour scheme, mode

**Black**:
The theme whose surfaces are all pure black, made for OLED screens; otherwise it is Dark.
_Avoid_: OLED, AMOLED, Midnight, true black

**Signal**:
The one colour a theme reserves for what needs attention: focus, the selected tab, a bookmarked star.
_Avoid_: Accent, highlight, brand colour
